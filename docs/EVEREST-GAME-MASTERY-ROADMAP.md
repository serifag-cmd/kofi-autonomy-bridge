# EVEREST GAME MASTERY ROADMAP

## Player-value architecture

### Layer 1 — First-minute delight
A premium reveal, immediate DALMA recognition, tactile roll, visible travel and a satisfying first reward.

### Layer 2 — First-session progression
Build something that visibly changes Genesis, open a chest, reveal a card, perform an attack/raid and unlock a clear next objective.

### Layer 3 — Habit without coercion
Daily recovery, rotating objectives, streaks with forgiveness, rotating events, collection completion and comeback rewards.

### Layer 4 — Mastery
World-specific modifiers, route choices, shield timing, build specialization, collection synergies and high-level optimization.

### Layer 5 — Social meaning
Async visits, guild projects, gifting, cooperative world milestones, rival vaults, shared events and opt-in leaderboards.

### Layer 6 — Infinite content
Data-driven worlds, seasonal rules, procedural route variation, event generators, collection sets and controlled content delivery.

## Longevity principles
1. Add depth before adding grind.
2. Add choices before adding currencies.
3. Reuse systems through data, not copy/paste code.
4. Every new world changes rules, not only colors.
5. Every reward should teach or advance something.
6. Every major action receives anticipation, impact and confirmation.
7. Protect players from dead ends, excessive loss and opaque economy behavior.
8. Measure retention hypotheses rather than assuming them.
