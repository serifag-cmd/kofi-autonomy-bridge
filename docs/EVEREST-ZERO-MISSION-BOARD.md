# EVEREST ZERO — Agent Mission Board

## Mission M01 — Market Discovery
Find 5 high-intent freelancer problems adjacent to scope creep where a browser utility could produce an immediate outcome and a €5–€25 digital product could plausibly follow.
Return evidence, competitors, distribution channels, and one smallest test per problem.

## Mission M02 — Product Attack
Audit the current Freelancer Rescue Kit and the free Scope Creep / Change Order tools.
Find the three largest product gaps that could plausibly affect payment conversion.
Do not redesign the whole system.

## Mission M03 — Red Team
Attempt to disprove the current model.
Specifically examine saturation, low willingness to pay, free-tool competition, acquisition difficulty, platform dependency and weak repeat usage.

## Mission M04 — Acquisition
Find organic distribution opportunities where a useful free scope/change-order utility can be introduced without spam or paid ads.
Focus on communities, search intent, templates, shareable outcomes and partnerships.

## Mission M05 — Automation
Map every manual action in:
research → build → publish → acquire → transaction → delivery → measurement.
For each one, propose an automation path and state its technical/platform constraint.

## Mission M06 — Economics
Model break-even and contribution for €9.90, €19.90 and €29.90 product variants using conservative transaction/direct-cost assumptions.
Identify which metrics must be observed before changing price.

## Mission M07 — UX
Audit the public hub on mobile-first principles. Identify friction in the first 60 seconds from arrival to completed useful result.

## Submission

Use the protocol's required return format. Attach screenshots, URLs, diffs or files whenever they are the evidence.
