ScopeGuard

Compara una nueva petición con el acuerdo original antes de comprometer horas.

Registra el alcance acordado, la petición nueva y las diferencias que hayas comprobado. ScopeGuard no decide por sí solo qué dice un contrato: hace explícitas las preguntas que debes resolver antes de aceptar el trabajo.

1. Contexto del proyecto

Describe el acuerdo original con suficiente precisión para compararlo.

2. Compara la petición con el acuerdo

Selecciona «Sí» solo cuando el acuerdo lo incluya claramente. «No» significa que la diferencia está comprobada; «No está claro» requiere aclaración.

Entregable
¿Es el mismo entregable ya acordado?
Cantidad / volumen
¿La cantidad solicitada está dentro del límite acordado?
Objetivo / resultado
¿Se mantiene el mismo propósito del trabajo?
Requisitos / funcionalidad
¿Se mantienen las especificaciones acordadas?
Ronda de revisión
¿La petición forma parte de una revisión incluida?
