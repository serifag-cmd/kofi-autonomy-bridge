# EVEREST ZERO Android APK

This Android project packages the published EVEREST ZERO Acquisition Hub as an installable Android WebView application.

Runtime URL:
https://weepy-darkseagreen-boards--unednachogarcia.replit.app

The APK is intentionally signed as a debug build by Gradle so it is directly installable on a personal Android device without a private release signing key.

Build target:
- applicationId: com.everest.zero
- minSdk: 24
- targetSdk: 35
- debug APK: app/build/outputs/apk/debug/app-debug.apk
