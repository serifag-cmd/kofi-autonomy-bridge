# Ko-fi publication checklist

Human-only publication step.

1. Ko-fi Shop → Add Product.
2. Choose Digital Product.
3. Paste the English or Spanish listing text from this folder.
4. Set price to €9.90 / 9,90 €.
5. Upload the ZIP: Freelancer-Rescue-Kit-v0.1.zip.
6. Add preview images if available.
7. Publish.
8. Copy the public product URL and return it to the EVEREST conversation.

After the product URL exists, the site CTA can point directly to checkout and the Ko-fi webhook can feed purchase events into the EVEREST measurement layer.

Do not paste passwords, API keys or private account credentials into chat.
